Mimic Log&Chat

Shared chat and dice log for Owlbear Rodeo

Install

Open Owlbear Rodeo → Extensions → Add extension URL:

https://mimiclog.friendlymimic.com/manifest.json

Publishing natively to Mimic Log&Chat

These tools post directly into the Mimic Log&Chat log without any bridge:

  • Owl20
  • ShadowDarklings Roller

Dice bridges

Mimic Log&Chat automatically picks up roll events from these extensions — no setup needed:

  • Owlbear Rodeo Dice
  • Battle System Bones
  • Battle System Friends
  • SD Character Sheet (by Max Paulus) — requires 2+ players in the room

Chat

Type in the input at the bottom of the panel and press Enter to send. Everyone in the room sees your message instantly.

  • Shift+Enter — insert a line break (multiline message)
  • Arrow Up / Down — cycle through your sent message history
  • /h — show the quick-reference help card in your log

Dice

Dice expressions are powered by dice-roller-parser and support standard RPG notation.

  • Inline — wrap anywhere in your message: [2d6] [1d20+4] [2d20kh1+5]
  • Shortcut — type a bare expression with no spaces and it rolls immediately: 2d6 → [2d6: 3+5] = 8

Images

Paste a direct image URL ending in .png .jpg .gif .webp or .svg and it renders inline. Clicking opens the original in a new tab.

Standard Markdown image syntax ![alt](url) also works.

GM-only messages

Messages flagged gmOnly: true are silently hidden from non-GM players. A shield icon marks them in the GM's log.

Developer API

Any OBR extension can post into the Mimic Log&Chat log using OBR.broadcast.sendMessage.

OBR.broadcast.sendMessage(
  'com.friendlymimic.mimic-chat/md',
  {
    md:     'The dungeon **rumbles**...',
    title:  'Dungeon Master',
    origin: 'com.yourext.yourext',
    gmOnly: false,        // optional
    id:     'unique-id',  // optional dedup key
  },
  { destination: 'ALL' }
)

See API-README.md for the full channel reference including HTML, local-macro, and auto player-name channels.
